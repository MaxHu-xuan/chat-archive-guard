# Support

ChatArchiveGuard is an early-stage, community-maintained project. Support is
best effort and has no response-time guarantee.

## Before opening an issue

1. Confirm that Python 3.11 or newer is in use.
2. Read the platform table and supported-format limits in `README.md`.
3. Reproduce the behavior with a newly created synthetic archive.
4. Run the unit tests and both privacy-audit commands from `CONTRIBUTING.md`.
5. Search existing GitHub issues for the same fixed finding category.

Use a GitHub bug report for reproducible defects and a feature request for
proposed scope changes. Include the package version, Python version, operating
system family, fixed finding categories, and minimal synthetic steps only.

Never attach or paste real archives, databases, credentials, personal data,
chat excerpts, screenshots, logs, absolute machine paths, or sensitive
filenames. Relative filenames in reports can also be sensitive metadata;
rename synthetic examples before sharing them.

Security vulnerabilities follow `SECURITY.md` and must not be disclosed in a
public support issue.
